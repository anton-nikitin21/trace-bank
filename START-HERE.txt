TRACE: ЛОКАЛЬНЫЙ ПРОСМОТР

1. Распакуйте весь архив.
2. Mac: откройте Start-Trace.command. Нужен Python 3.
   Если macOS блокирует запуск файла, откройте Терминал в этой папке
   и выполните: python3 start-local.py
3. Windows: откройте Start-Trace.bat. Нужен Python 3.
4. Откроется локальная страница demo.html без регистрации.
   Не закрывайте окно запуска, пока пользуетесь сайтом.

Первым открывается обучение. Также доступны обращения, проверка
документов, экономика с пояснением формул, исследование и история.
Главная страница и вход в рабочий кабинет сохранены.

Для проверки загрузите test-files/Trace-test-UPD.pdf в учебное обращение.
Проверьте распознанные поля и подтвердите их. Для сравнения нужны
платежи: они уже есть в первом учебном обращении.
В нём по договору Д-41 платёж равен 480 000, документ равен 470 000.
В обращении уже есть другие учебные документы, поэтому могут
появляться и другие замечания.

PDF, PNG, JPG, JPEG, TXT поддерживаются. Для загрузки библиотек
распознавания и языковых моделей нужен интернет. Документы
обрабатываются на устройстве. Данные сохраняются в этом браузере.
Оригиналы загруженных файлов доступны до перезагрузки страницы.
Это прототип на учебных данных, без общего серверного хранилища.

Основа доработок v3 — командный main, коммит 3af13d5.
Локальный запуск не меняет опубликованный сайт.

Обновление интерфейса: отдельно показаны ваши загрузки и учебные файлы.
Распознанные поля видны сразу под именем файла. Логотип перенесён
вправо вверх. Увеличены отступы форм и кнопок.

Обновление v3: замечания открываются отдельным окном; из него можно
проверить поля и повторить анализ. Статус снимается после устранения
причины. В экономике объяснены отрицательный эффект и порог расходов.
Логотип без фона возвращён влево вверх и обновлён внизу кабинета.
