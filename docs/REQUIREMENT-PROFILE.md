# Учебный профиль поставки supply-v1.1

Идентификатор входного профиля — supply-v1. Версия правил, записываемая в новые результаты, — supply-v1.1 от 10 ноября 2026 года. Утверждение и владелец банковского процесса не назначены.

- SUP-01 — обязательный договор по номеру и ИНН для каждой группы операций.
- SUP-02 — акт или УПД обязателен при полном расчёте. Для аванса это условие не применяется. Смешанный режим требует ручной оценки.
- SUP-03 — при полном расчёте сумма операций равна сумме действующих актов и УПД. Несколько версий одного первичного документа требуют выбора сотрудником до сравнения сумм.

Карточка показывает источники, отсутствие подтверждения и причины ручной оценки. Сквозные замечания, например проблемы извлечения или несвязанные файлы, остаются в общем результате. Даже при подтверждении всех трёх требований открытое сквозное замечание блокирует завершение.

Прежние браузерные проверки сохраняют исходный результат. Новая проверка создаёт новый снимок. Журнал и версии в демо хранятся в браузере. Для пилота понадобятся версионируемый реестр профилей, утверждение владельцем, область применимости, автор и срок действия, тесты каждой версии, серверные права и независимый аудит.
