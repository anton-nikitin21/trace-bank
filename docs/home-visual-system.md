# Trace homepage visual system

Scope: website/index.html. Employee workspace and authentication are unchanged.

Manrope variable (200–800), Cyrillic, hosted locally with its OFL license. Source: Google Fonts repository, ofl/manrope. Primary body weight 400, labels 500, headings 600. Monospace retained only inside technical records.

Roles: display 42–80px, section 34–56px, title 26–38px, body 16px, captions 12px. Mobile body 15px. Card radius 16px; control radius 10px; minimum button height 44–48px. Original navy/cyan palette retained.

The final scoped stylesheet design-system.css unifies earlier homepage surfaces and typography. Existing reveal, ambient, and depth animations remain separate.

Validation: local link/JS checks; browser desktop and 390px viewport; no horizontal overflow; hero controls remain below the preview panel.
