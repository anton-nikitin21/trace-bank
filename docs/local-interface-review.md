# Локальная доработка интерфейса Trace

## Scope and coverage

Область: очередь обращений → карточка клиента; фильтры, пустая выдача, навигация и окно создания обращения. Проверены локальные страницы `demo.html` и общий шаблон, из которого собирается `workspace.html`. Форма Clerk, главная страница, экономика и исследование не проходили полный визуальный аудит в этой итерации.

Стек: HTML, JavaScript без фреймворка, CSS и SVG. Сохранены Arial, существующая тёмная палитра и размеры из `tokens.css`. Прочитаны проектный AGENTS.md, CONTRIBUTING.md и redesign-notes.md. Применены better-interface и все шесть owning skills better-accessibility, better-layout, better-writing, better-typography, better-colors, better-ui.

| Domain | Evidence inspected | Result |
| --- | --- | --- |
| Accessibility | queue.js, шаблон, дерево доступности, Space, Enter, Escape, фокус заголовка и диалога | Исправлена потеря фокуса; осмотренный поток работает |
| Layout | Очередь, карточка, меню и диалог на стандартной ширине и 320 px | Уплотнена очередь; добавлено сворачиваемое мобильное меню |
| Writing | Статусы, подписи, пустая выдача, числовые формы | Исправлены формы числительных и повторяющиеся подписи |
| Typography | workspace-refine.css, вычисленные стили полей и таблицы | Ролевая шкала в rem, числа tabular-nums, мобильные поля 16 px |
| Colors | Вычисленные цвета поиска, подписей, таблицы и выбранного фильтра | Контраст границы поля 4.00:1, проверенные текстовые пары 7.60–17.32:1 |
| UI | Переключение вида, состояния фильтра, навигация, reduced-motion в CSS | Убрана плавная прокрутка при смене вида; переходы состояний 150 ms |

## Findings

Все перечисленные находки исправлены локально.

| Severity | Domain | Location | Before | After | Why |
| --- | --- | --- | --- | --- | --- |
| HIGH | Colors | `website/assets/workspace-refine.css:11` | Граница поиска #8cadd33b на #071222, расчётный контраст 1.53:1 | #62778f на фактическом #081426, 4.00:1 | Граница поля различима; WCAG 1.4.11 |
| HIGH | Accessibility | `website/assets/queue.js:83` | Кнопки фильтра пересоздавались при каждом обновлении | Стабильные узлы; обновляются только число и aria-pressed | После Space фокус остаётся на выбранной кнопке |
| MEDIUM | Accessibility | `website/assets/queue.js:58` | После открытия клиента фокус оставался в скрытом списке | Заголовок нового вида получает фокус, обновляется document.title | Пользователь клавиатуры получает контекст нового экрана |
| MEDIUM | Layout | `website/assets/workspace-refine.css:19` | Шесть пунктов меню занимали около трети узкого экрана | Кнопка «Разделы», aria-expanded, Escape, автоматическое закрытие после выбора | Основная работа начинается раньше; меню остаётся доступным |
| MEDIUM | Layout | `templates/workspace.html:6` | До таблицы шли подробная подсказка и сведения о хранении | Таблица следует за фильтрами; сведения и помощь расположены ниже | Список клиентов виден раньше при обычной высоте окна |
| MEDIUM | UI | `website/assets/workspace-refine.css:2` | Переход к обращению запускал плавную прокрутку и показывал промежуточную часть страницы | Мгновенный переход к началу рабочего вида | Предсказуемая смена экрана в частом действии |
| LOW | Writing | `website/assets/queue.js:75` | «3 платежей» | «3 платежа», Intl.PluralRules и Intl.NumberFormat | Корректные русские формы для любого количества |

## Verification

Пройдены:

- `python scripts/build_workspace.py` и `python scripts/build_workspace.py --check`.
- `python scripts/check_project.py`: локальные ссылки и 16 JavaScript блоков/файлов.
- `node scripts/test_browser_engine.cjs`: исходный/исправленный комплекты, защита фиксации и профиль.
- `node scripts/test_document_reader.cjs`: распознавание полей, TXT, валидация и отмена.
- `node scripts/test_document_workflow.cjs`: очередь, создание, TXT, подтверждение полей, платежи и сохранение. Для теста linkedom установлен отдельно в `../tmp/trace-design-checks`; зависимости продукта не изменены.
- Браузер: фильтр «На проверке» через Space → «Показано 2 из 3», aria-pressed=true и видимый outline; фокус не теряется.
- Браузер: поиск отсутствующего клиента → пустая выдача → сброс фильтров → полный список.
- Браузер: окно создания открывается с фокусом в поле; Escape возвращает фокус на кнопку создания.
- Браузер, 320 px: меню открывается Enter, закрывается Escape и при переходе; горизонтального переполнения нет (scrollWidth 305 при innerWidth 320, с учётом полосы прокрутки).
- Браузер: карточка клиента открывается с фокусом на H1 и scrollY=0.
- Измеренные пары: основной текст поля 17.32:1; подпись 9.82:1; заголовки таблицы 7.60:1; выбранный фильтр 8.33:1; граница поля 4.00:1.

Not verified: настоящий экранный диктор, реальный телефон, увеличение браузера 200%, RTL, отдельная эмуляция reduced-motion и forced-colors. Эти режимы не заявляются полностью проверенными. Полная проверка входа Clerk и его сетевых состояний не проводилась.

Снимки: `../output/trace-design-desktop.png` и `../output/trace-design-mobile.png`.

## Verdict

Approve — для осмотренного локального потока и перечисленных проверок; это не сертификация соответствия всего продукта WCAG. Изменения не закоммичены и не опубликованы.
