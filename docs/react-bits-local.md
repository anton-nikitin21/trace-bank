# Local visual refinement

React Bits references: FadeContent and SpotlightCard from https://github.com/DavidHDev/react-bits at e12c221. Native implementations live in website/assets/calm.js, with appearance in calm.css. Original license is retained in website/assets/react-bits.LICENSE.md.

Fade: 10px travel, 600ms, once on entering viewport. Spotlight: subtle neutral radial light on material cards, pointer devices only. Reduced-motion users receive static content. No React runtime, remote fonts, or new paid services.

Homepage palette: graphite #10151c, text #e5e9ed, muted #acb7c2, accent #b5cbd5. World exposure and saturation lowered; scanner and grids subdued. Continuous full-page scroll camera preserved.
