# Видеореференс: покадровая карта

Источник: IMG_7413.MP4, 720 × 1280, 30 fps, 8,9 с. Ключевые кадры: frames/, контактные листы: detail-1.jpg — detail-3.jpg. Анализ выполнен до изменений интерфейса.

Ролик снят камерой с экрана ноутбука, содержит ДВА сайта и монтажную склейку. Движение камеры, перспектива ноутбука, фон комнаты и водяные знаки не являются интерфейсом. Таймкоды описывают запись, а не абсолютную длительность анимаций оригинального сайта. Easing и размеры нельзя достоверно измерить из этой записи; ниже отделены наблюдения от предлагаемых настроек.

## Наблюдаемая последовательность

- **0,00–0,17**: чёрная заставка, небольшая светлая эмблема в центре, тонкий контур панели.
- **0,17–0,33**: светлая жёлто-зелёная панель раскрывается почти на весь экран. Эмблема остаётся в центре.
- **0,33–0,67**: панель сжимается к центру, скругления растут до крупного rounded rectangle, открывается интерфейс под ней. Переход морфологический, не простой fade.
- **0,67–1,00**: тёмный hero, фиксированная верхняя навигация; слева крупный заголовок, второе слово курсивом; справа стеклянная схема процесса, две компактные pill-кнопки под текстом.
- **1,00–1,50**: широкая объёмная световая лента течёт за содержимым; множество тонких светлых прожилок; затемнение по краям. Схема остаётся читаемой поверх.
- **1,50–2,00**: прокрутка hero вверх, навигация сохраняется, появляется ряд интеграций. Лента продолжается между секциями.
- **2,00–2,50**: следующий крупный заголовок слева и небольшое пояснение справа; снизу входит визуальная панель. Видно движение всего контента вслед за скроллом, доказательств scroll pinning в этой части нет.
- **2,50–3,00**: чередование текст/визуальная панель; следующая строка имеет панель слева, текст справа. Фон непрерывный.
- **3,00–3,50**: ещё один блок с заголовком слева и возрастающими объёмными колонками справа. Появление последовательное, точный stagger из ролика не измерим.
- **3,50–4,17**: светлая rounded-панель увеличивается и перекрывает экран. Это монтажный переход между двумя сайтами; не подтверждённый переход маршрутов одного приложения.
- **4,17–5,17**: второй сайт: тёмно-коричневый hero, крупная гротескная типографика с курсивным словом, справа вырезанные предметы (стакан и пакет), сверху навигация, снизу компактные факты. Сцена и объекты плавно раскрываются.
- **5,17–5,75**: прокрутка к контрастной светлой секции; предыдущая композиция уходит вверх, открывается большой заголовок из трёх строк.
- **5,75–7,00**: ряд четырёх предметных карточек с тонкими границами; крупные изображения, небольшие подписи и цена внизу; общий просторный ритм. В видео нет достоверного взаимодействия курсора с карточками.
- **7,00–7,50**: карточки уходят вверх; один стакан поднимается снизу в центр, вокруг него раскрывается круговой циферблат. Это переход композиции, связанный с прокруткой.
- **7,50–8,00**: предмет удерживается по центру циферблата, подписи находятся по краям. Затем сцена уходит вверх.
- **8,00–8,50**: возврат к тёмной сцене, крупный заголовок и увеличенный предмет в центре; предмет сдвигается/масштабируется при прокрутке.
- **8,50–8,90**: следующая предметная композиция, заголовок слева, объекты справа; движение продолжается в конце записи.

## Перенос в TRACE (адаптация, не буквальные данные ролика)

1. Заставка: один короткий цикл раскрытия/сжатия синей панели, центр — знак TRACE, только при первом входе в сессию; при reduced-motion заставка отсутствует.
2. Hero: сохранённый текст TRACE слева, реальные этапы проверки справа; непрерывная синяя световая лента позади; компактная навигация и pill CTA.
3. Последовательные этапы проверки: текущие тексты/данные из проекта; чередующиеся композиции, вход панелей снизу с небольшим масштабом, движение световой ленты по скроллу.
4. Структурированные карточки реальных разделов/материалов: ритм второго сайта, адаптированный к navy-палитре без кофейного контента.
5. Центральная композиция с этапами вокруг ядра TRACE: аналог циферблата из 7,0–8,0, без выдуманных метрик.
6. Кабинет и вспомогательные страницы: общие токены, стеклянные панели, состояния, та же навигация; логика, Clerk, поиск, проверка, журнал и реальные источники сохраняются.

## Предлагаемые настройки реализации

- reveal: 800–1100 мс, cubic-bezier(.16,1,.3,1), stagger 70–110 мс; это подобранные настройки, не измеренный easing исходника.
- intro: 900–1200 мс суммарно; pointer events не блокируются после завершения; контроль reduced-motion.
- интерактивные состояния: 180–280 мс; меню 350–450 мс с управлением клавиатурой.
- scroll-linked transform/opacity через requestAnimationFrame, без принудительного сглаживания нативного скролла.
- фон: отдельный SVG/CSS слой, пауза вне viewport/при скрытой вкладке; никаких новых WebGL-зависимостей без необходимости.

Не установлены по ролику: мобильная версия, раскрытие меню, hover, формы, авторизация и реальные переходы маршрутов. Для них используется согласованный визуальный язык, а не утверждение о точном копировании.
